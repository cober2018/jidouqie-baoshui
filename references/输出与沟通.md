# 输出与沟通

## 1. 归档结构

```text
私有资料目录/
  公司简称/
    公司档案.md
    对应年份和季度/
      季度财务报表.xls
      年度财务报表.xls      # 编制年报时
      编制说明.md
      记账明细.xlsx
      记账底稿.json
      原始资料/
```

校验完再替换成表。底稿里的 `上期` 应保存为 JSON 对象，以便离开临时目录后重算。原始资料按 [资料识别与核对](资料识别与核对.md#4-归档) 保存在私有目录。

## 2. 编制说明

- **结果摘要**。列本期营业收入、账面净利润、期末货币资金，以及待用户确认的款项。分别说明数字来自核对过的凭证还是推算。
- **资料和期间**。记录使用的文件、账期、重复或未采纳的资料、凭证缺口。
- **本期分录依据**。说明收入和费用、往来、工资社保、税费的判断，标注实际缴款和申报金额。留出被红冲的票、跨期事项和其他需要延续的处理。
- **主要报表变化**。记录本期与本年累计数、上期和本期期末变化及原因。分析现金余额时记录对账范围。
- **校验与待处理**。记录脚本校验、对照原始资料的核对结果和剩余问题。报表带有估算或缺少凭证时标记为草稿。

## 3. 向用户交付

用直白的语言说明营业收入、利润和季末余额，避免把收入等同于开票额、把费用等同于付出去的钱。报表推算的金额写清依据和核对范围。提供私有输出目录的链接及需要用户办理的事项。避免在回复里贴整张报表、完整账户或个人信息。

## 4. 申报结果回填

1. 读取归档的 `记账底稿.json`，确认主体、税种、所属期，以及资料是申报结果还是缴款凭证。
2. 申报结果用于核对所属期的税款金额及原估算，缴款按真实支付日期记账。跨期或已归档的事项先确认需要重编哪个期间，避免重复入账。
3. 在临时目录重算并核对 `ledger.py` 和 `fill_report.py` 的产物，然后更新受影响的报表、记账明细、编制说明、底稿和公司档案。
4. 提供调整前后的金额、影响的报表行及还有待核实的事项。
