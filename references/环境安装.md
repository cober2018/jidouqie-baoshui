# Python 环境安装

脚本入口需要 Python 3.8+ 和可用的 `venv`。首次安装会用 pip 下载 `xlrd`、`xlwt`、`xlutils`、`pdfplumber`、`openpyxl` 及其依赖，之后复用环境。安装过程无需提供发票、流水等资料。

在安装好的 skill 文件夹中运行。

**macOS / Linux**

```bash
PY="$(python3 scripts/setup_env.py)"
"$PY" -I scripts/ledger.py --help
```

**Windows PowerShell**

```powershell
$Py = py -3 scripts/setup_env.py
& $Py -I scripts/ledger.py --help
```

Windows 没有 `py` 时可用 `python`。成功时脚本在标准输出打印虚拟环境里的 Python 路径，后续使用这个解释器执行各脚本。

## 环境目录

设置 `JIDOUQIE_BAOSHUI_VENV` 时使用指定目录。否则优先用用户缓存目录，无法写入时尝试当前目录下的 `.jidouqie-baoshui-env`。

| 平台 | 默认缓存路径 |
|---|---|
| Unix | `${XDG_CACHE_HOME:-$HOME/.cache}/jidouqie-baoshui/venv` |
| Windows | `%LOCALAPPDATA%\jidouqie-baoshui\venv` |

## 排障

- 找不到 Python 或版本过旧时，从 [Python 官网](https://www.python.org/downloads/) 或系统包管理器安装受支持版本。
- 缺少 `venv` 时，安装所用 Python 的虚拟环境组件。例如 Debian/Ubuntu 的系统 Python 可安装 `python3-venv`。
- 下载失败时，先确认当前环境允许联网并检查 pip 源或网络配置。默认源失败后脚本会尝试清华和阿里云的 PyPI 镜像。
- 无权写入时，把 `JIDOUQIE_BAOSHUI_VENV` 指向专门存此环境的可写目录。
- 查看错误信息时，先确认输出中是否含本地路径、代理配置或财务资料。对外反馈只附合成样本和必要的报错片段。
