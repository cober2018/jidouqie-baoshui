# jidouqie-baoshui

给 Claude Code 或 Codex 使用的中文记账 skill。辅助执行小企业会计准则、按季报送财务报表的小规模纳税人整理票据、核对银行流水并制作财务报表。

根据复核过的凭证和分录生成资产负债表、利润表、现金流量表及记账明细。报表提交与缴税由用户办理。提交前核对源凭证、报表行次和适用的申报口径。

## 安装

从项目目录安装到 Claude Code，需已安装 Node.js 和 npm。

```bash
npx skills add jidouqie/jidouqie-baoshui --skill jidouqie-baoshui -a claude-code
```

Codex 用相同命令并将 `-a claude-code` 换成 `-a codex`。需要全局安装时加 `-g`。也可以克隆仓库后，把包含 `SKILL.md` 的完整文件夹放入客户端的 skills 目录。Python 3.8+ 的安装和首次依赖下载见 [环境安装](references/环境安装.md)。

## 使用

1. 在仓库外建一个资料和产物目录。准备上期财务报表、发票导出表、银行流水，按业务补充工资、社保、税费及其他凭证。
2. 在客户端指定该目录和要编制的期间。例如「用 jidouqie-baoshui 编制指定目录里的本季财务报表，先列出需要我核对的事项」。
3. 核对资料和未匹配的收付款。上期数据、收付证据或申报口径不完整时，先核对标明缺项的草稿。
4. 取回报表、编制说明、记账明细和底稿。用户取得申报或缴款结果后，可以用同一底稿回填。

[SKILL.md](SKILL.md) 列出了各脚本的运行顺序和参数。支持部分发票 `.xlsx` 导出和文本型电子发票 PDF、部分上一期的 PDF 或 `.xls` 报表，以及提供日期、收支和余额列的银行 `.xls`、`.xlsx`、`.csv`。扫描件、版式不同的导出文件和脚本未识别的行需要人工复核。

## 报表模板

从主管电子税务局的「财务报表报送」入口下载与企业准则和报送期间一致的空白模板，存放在资料目录。第四季度季报和年报需要分别下载。导出步骤可参考 [国家税务总局山西省税务局的操作说明](https://shanxi.chinatax.gov.cn/upload/file/20240729/1722240789371092183.pdf)。

填表脚本按工作表名称前缀找表，每类需要一张，顺序不限。各表第 3 行应包含「纳税人识别号」「纳税人名称」，第 4 行应包含「所属期起」「所属期止」，右侧留有填写位置。每个「行次」列右侧紧接两列金额，所有行次应当是完整且不重复的正整数。

| 工作表名称前缀 | 行次 | 月季报金额列 | 年报金额列 |
|---|---|---|---|
| 资产负债表 | 1–53 | 期末余额、年初余额 | 期末余额、年初余额 |
| 利润表 | 1–32 | 本期金额、本年累计金额 | 本年累计金额、上年金额 |
| 现金流量表 | 1–22 | 本期金额、本年累计金额 | 本年累计金额、上年金额 |

年报需要提供利润表和现金流量表的上年金额，缺少任何一张表的对比数据，脚本会停止填表。各地文件格式可能不同。先核对版式、行次和填写结果，再按当地要求上传。

## 资料保护

脚本直接读取本地输入文件并写出本地结果，环境安装脚本联网下载 Python 依赖。客户端能看到的内容及其数据处理方式取决于客户端及账户设置。凭证和生成的报表、底稿、临时文件及日志都可能含敏感数据。真实税号、发票号码、账号和工资记录留在私有工作目录。提交 GitHub issue 时使用合成样本。
